    How to update and reference this roadmap
    1. Edit only the embedded roadmap-data JSON for ordinary card, status, topic, or rationale updates.
    2. Keep one bounded concern per card and three to five entries under Topics covered.
    3. Run node --test .agents/tests/project-roadmap.test.js, then open this file locally and inspect the detailed and overview views.
    4. In future handoffs, cite docs/project-roadmap.html and identify the card being started or completed instead of pasting the diagram.

    One card represents one bounded concern. A cross-repository concern may require coordinated frontend and backend PRs. Evidence-gathering cards may reveal additional independent concerns, which must be added as new cards rather than hidden inside existing scope.
